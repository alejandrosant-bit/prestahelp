Seguridad

Actívalo si no quieres que otra persona pueda entrar a la app desde este teléfono, aunque la sesión quede guardada. Necesitas tener configurada la huella o el rostro en el teléfono.

Nuevo préstamo

Con Venezuela o Colombia elegidos, escribe el número sin el 0 inicial (ej. 4141234567). Con "Otro", escribe el número completo incluyendo su código de país.

Se calcula sola según el plan, pero puedes cambiarla a mano si acordaste otra fecha con el cliente.

Editar préstamo

Con Venezuela o Colombia elegidos, escribe el número sin el 0 inicial (ej. 4141234567). Con "Otro", escribe el número completo incluyendo su código de país.

Si cambias el monto, el interés, el plan o la fecha de inicio, el cronograma se recalcula solo (los pagos ya marcados no se pierden).

Cronograma de cuotas

Toca una cuota para marcarla como pagada. Tócala de nuevo para desmarcarla o borrarla, en caso de un error.
